# Lista de Verificação - Entrega 5

!!! warning "Versão anterior (1.0) — mantida para rastreabilidade"
    Esta página é a versão 1.0 da lista e foi mantida sem alterações de conteúdo. A versão atual está em [v2/verif5.md](v2/verif5.md). Os itens 1–14 desta página têm o mesmo número, com prefixo G, na v2.0. O [índice das listas de verificação](index.md) mostra onde está cada versão e o que mudou.

## 1. Orientações

Esta lista verifica se os artefatos da Entrega 5 incluem os elementos necessários para avaliar um protótipo de papel e relatar os resultados. Para cada pergunta, deve-se marcar apenas uma opção: **Conforme**, **Não conforme** ou **Não se aplica**.

---

## 2. Perguntas de verificação

| 5 | O método escolhido permite que uma pessoa simule tarefas usando telas e peças de papel antes da implementação do sistema? | ☐ | ☐ | ☐ | [Gabriel Melo](https://github.com/gabriellcardone-06) |

| 8 | O protótipo prevê as telas, cartões, menus, mensagens e outras peças móveis necessárias para executar as tarefas propostas? | ☐ | ☐ | ☐ | [Igor Dantas](https://github.com/IgorDARAUJO) |

## 1. Orientações

Esta lista verifica se os artefatos da Entrega 5 incluem os elementos necessários para avaliar um protótipo de papel e relatar os resultados. Para cada pergunta, deve-se marcar apenas uma opção: **Conforme**, **Não conforme** ou **Não se aplica**.

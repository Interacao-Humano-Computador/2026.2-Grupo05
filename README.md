# Avaliação de Usabilidade e IHC: Portal SEMOB-DF

Projeto acadêmico desenvolvido para a disciplina de **Interação Humano-Computador (IHC)** na Universidade de Brasília (UnB), sob a orientação do **Prof. André Barros**.

---

## Sobre o Projeto

Este repositório é dedicado à análise, avaliação de usabilidade e proposta de redesenho de interfaces para o portal da **Secretaria de Estado de Mobilidade do Distrito Federal (SEMOB-DF)**. 

O objetivo central do trabalho é aplicar métodos e técnicas de IHC para identificar problemas de navegabilidade, barreiras de acessibilidade e oportunidades de melhoria na experiência do cidadão ao utilizar os serviços públicos prestados pela plataforma.

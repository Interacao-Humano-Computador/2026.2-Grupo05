# Projeto da disciplina Interação Humano-Computador: Portal SEMOB-DF

Projeto acadêmico desenvolvido para a disciplina de **Interação Humano-Computador (IHC)** na Universidade de Brasília (UnB) — FCTE, semestre **2026/2**, sob a orientação do **Prof. André Barros de Sales**.

## Sobre o Projeto

A **Secretaria de Estado de Transporte e Mobilidade do Distrito Federal (SEMOB-DF)** é o órgão governamental responsável pelo planejamento, regulamentação, fiscalização e gestão das políticas de transporte público coletivo e mobilidade urbana no DF. Seu portal ([semob.df.gov.br](https://www.semob.df.gov.br/)) centraliza serviços essenciais como consulta de itinerários, emissão do Passe Livre Estudantil e informações sobre o Cartão Mobilidade.

O objetivo central deste projeto é aplicar, de forma prática, os métodos e técnicas de IHC aprendidos em sala de aula.

> Este projeto possui **finalidade estritamente acadêmica**, sem qualquer vínculo institucional com a administração pública do Distrito Federal.
